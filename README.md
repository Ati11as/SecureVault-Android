# SecureVault 2.1

Исправленная версия MVP защищённого файлового хранилища.

## Включено
- AES-256-GCM + Android Keystore
- PIN минимум 6 цифр
- биометрическая разблокировка, если устройство её поддерживает
- импорт нескольких файлов
- поиск
- сортировка
- карточки с типом и размером
- просмотр через Android Intent + корректный FileProvider
- временная расшифровка в cache
- автоматическое удаление временного preview при закрытии диалога
- удаление файлов
- FLAG_SECURE
- отключён Android backup приложения

## Важное замечание
Версия предназначена как исходный проект/MVP. Для реального security-sensitive продукта нужен аудит, rate limiting PIN, более сильный KDF для PIN, защита метаданных и продуманная модель восстановления/смены ключей.
